## Running the Notebooks

1. Open the required project folder and read its `README.md`.
2. Install the dependencies listed by that project. For example:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```

3. Start Jupyter Notebook or JupyterLab:

   ```bash
   jupyter notebook
   ```

4. Open the project's notebook and run the cells in order. If the notebook uses an external dataset, follow the dataset source and setup instructions in that project's README.

The example installation command covers common libraries only; install any additional dependencies required by the individual project.
